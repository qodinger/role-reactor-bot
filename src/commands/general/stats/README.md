# Stats Command

## Overview

The `/stats` command displays bot statistics and usage information.

## Usage

```
/stats
```

## What It Shows

- **Total Servers** - Number of servers the bot is in
- **Active Servers** - Servers with recent activity
- **Total Users** - Total users across all servers
- **Command Usage** - Number of commands executed

## Permissions

No special permissions required - available to all users.
