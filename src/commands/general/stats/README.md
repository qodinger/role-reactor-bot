# Stats Command

## Overview

The `/stats` command displays bot statistics and usage information.

## Usage

```
/stats
```

## What It Shows

- **Total Servers** - Number of servers the bot is in
- **Active Servers (30d)** - Servers with recent activity
- **Total Users** - Total users across all servers
- **Commands Today** - Number of commands executed today
- **All-time Commands** - Total commands executed since bot startup
- **Feature Usage** - Usage statistics for Auto-Mod, Welcome, Temp Roles, Giveaways

## Permissions

No special permissions required - available to all users.
