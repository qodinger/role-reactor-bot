# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.7.x   | ✅        |
| < 1.7   | ❌        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Please report it privately through our Discord support server:

👉 **[Join Support Server](https://discord.gg/D8tYkU75Ry)**

Open a ticket and include as much detail as possible:
- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

You will receive a response within **48 hours**. We will work with you to understand and resolve the issue before any public disclosure.

## Security Disclosure Policy

- We will acknowledge receipt of your report within 48 hours
- We will investigate and provide an estimated fix timeline
- We will notify you when the fix is released
- We will credit you in the release notes (unless you prefer to remain anonymous)

## Known Fixed Vulnerabilities

- **v1.7.1** (2026-04-01): API endpoints hardened to prevent unauthorized access to user data and server settings.
